# Aurora 2 · Preview 84

Experimental Windows agent harness with a conversation Control Panel, visual Switchboard, goals/memory, desktop commands and an execution inspector. Built primarily for technical AI operators; a human can explore it with setup help. Broad capabilities remain available through Advanced controls.

**Release:** November 6, 2026 · `preview-2026.11.06-r84`. Read [human setup](README_FOR_HUMANS.md), [AI setup](README_FOR_AI.md), [upgrade steps](UPGRADING.md) and [release notes](RELEASE_NOTES.md). Install into a separate folder and start paused with your own credentials.

Since Preview 54: stronger task intent/continuation, optional capture batching and bounded waits, memory identity/projection repairs, durable queued-input recovery with explicit retry and duplicate protection, exact execution evidence, optional recording/history and recovery capacity/archive previews. Old modes and settings remain selectable.

Earlier scoped subscription Pokémon runs completed parcel delivery, updated goals and used multiple game commands per batch. One matched 20-minute comparison retained 162 rather than 303 frames with the same 161 model requests; that does not establish a general speedup or broad desktop reliability. Navigation, long-session recovery, display calibration and wider website acceptance remain ongoing. This release adds offline regression evidence, not a new live endurance claim.

OpenAI API-key access and scoped ChatGPT subscription inference have been exercised; OAuth sign-in alone does not guarantee account/model availability or refreshed long sessions. No credentials, personal logs, recovery stores, screenshots, recordings, ROMs or saves ship here. Five named UI artwork assets are included.
