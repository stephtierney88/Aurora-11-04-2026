# Preview roadmap

Conversation-first Control Panel, Switchboard controls/command browser, inspectable context flow and current model defaults are implemented. Next reliability stops: evidence-aware scene classification (token boundaries, negation, recency and receipt contamination) and G1 recursive/atomic goal persistence with unique IDs; then bounded gameplay revalidation. Also pending: message delivery/receipt presentation, exact request provenance, screenshot coordinates/background capture acceptance, clean-machine GUI use, retrieval publication/concurrency and measured performance. Range message deletion, fuller horizons, versioned memory and provider integrations remain staged. See README for tested limits.
