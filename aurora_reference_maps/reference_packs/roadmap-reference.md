# Aurora preview roadmap — November 6, 2026

Current release: Preview 84, `preview-2026.11.06-r84`. Keep commands, aliases and legacy/Advanced settings available. Inventory: 410 bindings / 180 reviewed contracts / 54 settings / 24 views.

| Area | Implemented foundation | Next |

Near-term engineering order: finish verified archive lookup/activation, then return to granular memory and retrieval/command contracts. Shell/audio durability and a guided startup wizard remain follow-ups. Native testing in the development environment is paused after reported lag; guarded offline tests are separate evidence. New users should authorize and bound their own local calibration/actions.

No percentage-to-finished or production-readiness claim applies. Public updates are deliberate sanitized snapshots with annotated tags; the development repository may advance between releases.
