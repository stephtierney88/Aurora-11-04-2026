# Optional controls and turn flow

This stable reference key remains available without the private historical research ledger. Aurora exposes controls through shared typed settings, commands, CLI and Advanced views; see [the registry reference](aurora-settings-registry-reference.md) and [AI guide](../../README_FOR_AI.md).

Visibility, capability enablement, execution permission, scheduling, persistence and billing are separate. Profiles must show their setting changes. Drafts are not effective state until applied; versioned receipts/rollback remain authoritative. Preserve existing command aliases and valid saved configurations.

Command-driven capture and reviewed readback wakes can avoid periodic waits. A new image still needs a new inference request; this is not a tool call returning inside an already-running inference. Optional bounded tasks provide admission limits and declared outcomes; token thresholds are not hard dollar caps. Optional bounded subscription inference adds local cancellation, not proof of provider cancellation. See [release notes](../../RELEASE_NOTES.md) for tested limits and [roadmap](../../docs/notes/aurora_runtime_roadmap.md) for future work.
