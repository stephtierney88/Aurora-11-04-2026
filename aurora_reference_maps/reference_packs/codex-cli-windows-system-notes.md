# Windows setup assistance

Use [the AI setup guide](../../README_FOR_AI.md) and [upgrade instructions](../../UPGRADING.md) for this snapshot. Check installed Python/Tk, use the local `.venv`, run both preflights and start paused. Do not copy another application's OAuth cache or assume a model name proves provider routing.
