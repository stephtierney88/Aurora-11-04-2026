# Harness research: implementation boundary

This reference key is retained for compatibility. Private comparative research and old local source probes are omitted from the public runtime package. This file does not install or enable another agent framework.

Aurora's implemented foundations include command discovery, typed settings/transactions, correlated receipts, owned inputs, optional bounded continuation, and retained memory/retrieval controls. General-purpose recursive language-model analysis, an isolated programmable REPL, automatic skill creation and specialist-agent orchestration are future research candidates, not shipped features inferred from those foundations.

Use [the runtime map](../../aurora_reference_maps/runtime/overview.md), [capability commitment](../../docs/notes/aurora_capability_compatibility.md) and [current roadmap](../../docs/notes/aurora_runtime_roadmap.md). Adopt future ideas behind explicit settings with compatibility defaults, measured evidence, ownership boundaries and failure/cancellation tests. Keep full command/detail access rather than deleting capabilities to simplify the surface.
